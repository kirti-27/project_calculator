# project_calculator
A lightweight calcultor that handles basic arithmetic with a clear and easy interface.It's built to be simple,fast and beginner friendly.
## Features
- Addition
- Subtraction  
- Multiplication
- Division
- Power calculation

## Requirements
- Java 11 or higher
- Maven 3.6 or higher

## Building and Running

### Compile and Run:
```bash
mvn compile
mvn exec:java -Dexec.mainClass="com.calculator.Main"
